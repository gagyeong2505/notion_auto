[개요] gws-executor.md
위치: agent1114/.claude/agents/gws-executor.md
역할: 승인된 후속 작업을 GWS CLI로 실행하는 서브에이전트

1. 프론트매터
   - name, description
   - tools: Bash(gws 명령), Read, Write(outputs 폴더)

2. 담당 작업
   - Gmail: 메일 초안 작성 / 발송
   - Drive·Docs·Sheets: 파일 생성, 내용 작성
   - Calendar: 일정 등록

3. 실행 원칙
   - 승인된 작업만 실행
   - 메일은 기본적으로 '초안 생성'까지 하고, 발송은 별도로 승인받음
   - 실행 전 실제로 실행할 gws 명령을 보여줌

4. 참조
   - gws-execute 스킬의 reference 문서(gmail, drive-docs, calendar)
   - templates/email 폴더의 메일 템플릿

5. 출력
   - 실행한 명령, 결과(메일 초안 링크, 파일 링크, 일정 링크)
   - logs/actions.md에 기록할 내용
