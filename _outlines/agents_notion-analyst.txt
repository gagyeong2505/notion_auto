[개요] notion-analyst.md
위치: agent1114/.claude/agents/notion-analyst.md
역할: Notion DB 조회·분석 전담 서브에이전트 (읽기 전용)

1. 프론트매터
   - name, description(언제 호출되는지)
   - tools: Notion 조회 도구만 허용(search, fetch, query 계열). 쓰기 도구 제외.

2. 담당 업무
   - 트리거 DB 조회: 키워드 → 대상 DB, 기본 동작, 후속 작업, 기본값 확인
   - 대상 DB 조회: 날짜·상태·담당자 조건으로 필터링
   - 분석 요청 처리: "오늘 마감", "이번 주 지연", "미완료 업무" 등

3. 입력
   - 메인 세션에서 넘겨준 요청 원문 또는 조회 조건

4. 출력 형식
   - templates/report.md 형식에 맞춘 요약
   - 후속 작업 후보 목록(예: 마감 알림 메일 초안 필요 여부)

5. 금지 사항
   - 페이지 생성·수정·삭제 금지
   - 추측으로 속성 이름 사용 금지 → docs/notion-schema.md 기준
