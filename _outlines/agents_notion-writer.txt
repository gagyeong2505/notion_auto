[개요] notion-writer.md
위치: agent1114/.claude/agents/notion-writer.md
역할: 승인된 항목을 Notion 대상 DB에 등록·수정하는 서브에이전트

1. 프론트매터
   - name, description
   - tools: Notion 페이지 생성·수정 도구 + 조회 도구

2. 실행 조건
   - 사용자가 미리보기를 확인하고 승인한 항목만 처리
   - 승인 정보가 없으면 실행하지 않고 메인 세션으로 되돌림

3. 처리 절차
   - 대상 DB의 속성 구조 확인(docs/notion-schema.md)
   - 트리거 DB의 '기본값' 적용(예: 상태=예정)
   - 페이지 생성 후 생성된 페이지 링크 반환

4. 오류 처리
   - 필수 속성 누락, 날짜 형식 오류, 권한 오류 시 원인과 함께 보고
   - 부분 성공 시 성공/실패 항목을 나눠 보고

5. 출력
   - 등록 결과(제목, 대상 DB, 페이지 링크)
   - 후속 작업이 지정된 경우 gws-executor로 넘길 정보
