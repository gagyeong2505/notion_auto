[개요] approval-policy.md
위치: agent1114/docs/approval-policy.md
역할: 승인 없이 할 수 있는 작업과 승인이 필요한 작업의 기준

1. 승인 없이 실행 가능
   - Notion 검색·조회·분석
   - 로컬 outputs 폴더에 초안 작성
   - 로그 기록

2. 승인 필요 (1회 승인)
   - Notion 페이지 생성·수정
   - Gmail 초안 생성
   - Drive 문서·시트 생성
   - Calendar 일정 등록

3. 별도 재확인 필요
   - 메일 실제 발송
   - Notion 페이지 삭제 또는 대량 수정(5건 이상)
   - 외부 사람과 파일 공유

4. 승인 방식
   - 미리보기 제시 후 "승인 / 수정 / 취소" 중 하나로 응답받기
   - 여러 건일 때 번호를 붙여 일부만 승인할 수 있게 함

5. 승인 범위
   - 한 번의 승인은 그 미리보기 내용에만 적용됨(다음 작업에 이어지지 않음)
