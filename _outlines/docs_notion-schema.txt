[개요] notion-schema.md
위치: agent1114/docs/notion-schema.md
역할: 연결된 Notion DB들의 구조를 정리한 기준표 (Notion을 실제로 조회해서 채움)

1. 연결 페이지 정보
   - 루트 페이지 이름, 링크

2. 트리거 키워드 DB
   - DB ID / 링크
   - 컬럼 이름과 유형(가이드와 실제가 다른 점 표시)

3. 대상 DB별 구조 (DB마다 반복)
   - DB 이름, ID, 링크
   - 속성 목록: 이름 / 유형 / 필수 여부 / 선택지 값
   - 날짜 속성 이름(마감일, 일정일 등)
   - 상태 값 매핑(예: 예정 / 진행중 / 완료)

4. 요청 표현 → 조회 조건 매핑
   - "오늘 마감" → 마감일 = 오늘 AND 상태 ≠ 완료
   - "지연" → 마감일 < 오늘 AND 상태 ≠ 완료

5. 갱신 기록
   - 마지막으로 확인한 날짜, 변경 내용
