[개요] notion-trigger-db-guide.md
위치: agent1114/docs/notion-trigger-db-guide.md
역할: 사용자가 Notion에 직접 만드는 「트리거 키워드」 DB의 작성 가이드

1. 트리거 DB의 목적
   - 키워드 → 등록할 표를 연결하는 표. 사용자가 직접 관리한다.
   - 키워드를 추가하거나 바꿀 때 로컬 파일은 수정하지 않는다.

2. 컬럼 정의
   - 키워드(제목): 예) 개인, 업무
   - 별칭(텍스트): 쉼표로 구분, 예) 사적, p
   - 대상 DB(URL): 항목을 등록할 Notion DB 링크
   - 기본 동작(선택): 등록 / 조회
   - 후속 작업(다중 선택): 캘린더, 메일, 문서
   - 기본값(텍스트): 예) 상태=예정, 우선순위=보통
   - 사용 여부(체크박스): 끄면 그 키워드는 무시

3. 작성 예시
   - 개인 → 개인일정 DB / 등록 / 캘린더
   - 업무 → 업무일정 DB / 등록 / 캘린더, 메일

4. 작성 규칙
   - 키워드는 중복 금지(별칭 포함)
   - 대상 DB는 Notion 연결 권한이 있는 페이지 안에 있어야 함
   - 키워드에 콜론(:) 사용 금지

5. 사용 예
   - 입력 "개인: 친구와 카페 약속 내일 3시" → 개인일정 DB에 등록

6. 자주 생기는 문제
   - 키워드가 인식되지 않음 / 대상 DB에 접근 권한 없음 / 기본값 형식 오류
