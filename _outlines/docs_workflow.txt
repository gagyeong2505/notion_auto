[개요] workflow.md
위치: agent1114/docs/workflow.md
역할: 요청이 들어와서 기록되기까지의 전체 처리 흐름

1. 흐름 A: 등록 (트리거 키워드 있음)
   ① 입력 수신: "개인: 친구와 카페 약속"
   ② 키워드 분리 및 트리거 DB 조회
   ③ 내용 해석(제목, 날짜, 시간, 장소)
   ④ 미리보기 제시 → 사용자 승인
   ⑤ notion-writer가 대상 DB에 등록
   ⑥ 후속 작업이 있으면 미리보기 → 승인 → gws-executor 실행
   ⑦ logs/actions.md 기록

2. 흐름 B: 분석 (키워드 없음)
   ① 입력 수신: "오늘 마감 작업 확인해줘"
   ② notion-analyst가 조회·분석
   ③ 보고서 제시(templates/report.md)
   ④ 후속 작업 제안 → 승인 → gws-executor 실행
   ⑤ 기록

3. 흐름 C: 예외
   - 없는 키워드 / 날짜를 해석할 수 없음 / 대상 DB 접근 실패
   - 사용자가 승인 거절 또는 수정 요청 → 미리보기 다시 작성

4. 흐름도
   - 위 흐름을 한눈에 보는 다이어그램(텍스트 또는 Mermaid)
