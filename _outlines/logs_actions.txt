역할: 실행 이력 기록 (무엇을, 언제, 누가 승인했는지)

1. 기록 형식(표 형식, 한 작업당 한 줄)
   - 일시 / 입력 원문 / 인식된 키워드 / 흐름(등록·분석) / 대상 DB 또는 GWS 기능
   - 승인 여부 / 결과(성공·실패) / 결과 링크 / 비고

2. 기록 규칙
   - 최신 기록을 아래쪽에 추가
   - 실패한 경우 원인을 비고에 남김
   - 승인을 거절한 작업도 기록

3. 정리 규칙
   - 월이 바뀌면 이전 기록은 별도 파일로 옮김(예: actions-2026-11.md)
