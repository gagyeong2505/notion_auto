[개요] 스킬 (.claude/skills)
위치: agent1114/.claude/skills/
현재 상태: skills 폴더만 만들었고, 아래 하위 폴더와 SKILL.md는 추후에 만든다.
각 스킬 구조: .claude/skills/<스킬이름>/SKILL.md (+ 필요하면 reference 폴더)

────────────────────────────────
1. trigger-router  (진입점)
────────────────────────────────
역할: 입력에서 키워드를 분리하고 트리거 DB를 조회해서 어느 흐름으로 보낼지 결정
- 프론트매터: name, description("키워드: 내용" 형식의 입력이 들어왔을 때 사용)
- 처리 절차
  ① 첫 번째 콜론(:) 앞부분을 키워드로 분리(앞뒤 공백 제거)
  ② 트리거 DB에서 키워드·별칭과 비교(사용 여부가 켜진 것만)
  ③ 일치하면 → 기본 동작에 따라 notion-db-register 또는 notion-db-analyze로 넘김
  ④ 일치하지 않으면 → 사용 가능한 키워드 목록을 안내
- 하위 참조 문서
  · reference/parsing-rules.md: 날짜·시간 표현 해석("내일", "다음 주 월요일", "3시")
  · reference/fallback.md: 없는 키워드, 키워드 없는 입력, 콜론이 여러 개인 경우

────────────────────────────────
2. notion-db-register
────────────────────────────────
역할: 트리거로 정해진 대상 DB에 항목 등록
- 처리 절차
  ① 대상 DB 속성 구조 확인(docs/notion-schema.md)
  ② 입력 내용을 속성에 맞게 나눔(제목, 날짜, 장소, 메모)
  ③ 트리거 DB의 기본값 적용
  ④ templates/register-preview.md 형식으로 미리보기 → 승인
  ⑤ notion-writer 서브에이전트로 등록
  ⑥ 후속 작업이 있으면 gws-execute로 넘김
- 주의: 승인 없이 등록 금지

────────────────────────────────
3. notion-db-analyze
────────────────────────────────
역할: 키워드 없는 조회·분석 요청 처리(예: "오늘 마감 작업 확인해줘")
- 처리 절차
  ① 요청 표현을 조회 조건으로 바꿈(docs/notion-schema.md의 매핑 기준)
  ② notion-analyst 서브에이전트로 조회
  ③ templates/report.md 형식으로 보고
  ④ 후속 작업 제안 → 승인 → gws-execute로 넘김
- 주의: 이 스킬에서는 Notion 쓰기를 하지 않음

────────────────────────────────
4. gws-execute
────────────────────────────────
역할: 승인된 후속 작업을 GWS CLI 명령으로 실행
- 처리 절차
  ① 작업 종류 확인(메일 / 파일 / 일정)
  ② 해당 reference 문서를 읽고 명령 구성
  ③ 실행할 명령 미리보기 → 승인 → gws-executor 서브에이전트로 실행
  ④ 결과 링크 보고, logs/actions.md 기록
- 하위 참조 문서
  · reference/gmail.md: 초안 생성, 발송, 템플릿 변수 채우기
  · reference/drive-docs.md: 문서·시트 생성, 폴더 지정
  · reference/calendar.md: 일정 등록, 시간대(Asia/Seoul), 알림 설정
- 사전 준비: gws CLI 설치 및 Google 계정 인증(현재 PC에 미설치)

────────────────────────────────
스킬 간 연결 요약
────────────────────────────────
입력 → trigger-router ┬→ notion-db-register → (후속 작업) → gws-execute
                     └→ notion-db-analyze  → (후속 작업) → gws-execute
키워드 없는 입력 ──────→ notion-db-analyze
