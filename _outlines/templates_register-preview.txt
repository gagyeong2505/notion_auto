1. 머리말
   - 인식된 키워드 → 대상 DB 이름

2. 등록될 내용(표 형식)
   - 속성 이름 / 입력될 값 / 출처(입력에서 해석 / 기본값 / 비어 있음)

3. 해석 확인 사항
   - 모호하게 해석한 부분 표시(예: "내일" → 2026-11-15)

4. 후속 작업 예정
   - 예) 캘린더 등록 예정

5. 선택지
   - 승인 / 수정(어느 항목을 어떻게) / 취소
