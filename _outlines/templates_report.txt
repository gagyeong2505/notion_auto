[개요] report.md
위치: agent1114/templates/report.md
역할: 분석 결과를 사용자에게 보고하는 형식

1. 요약 한 줄
   - 예) 오늘 마감 3건, 그중 미완료 2건

2. 상세 목록(표 형식)
   - 제목 / DB / 마감일 / 상태 / 담당자 / Notion 링크

3. 주의 항목
   - 지연, 담당자 미지정, 마감일 누락

4. 제안하는 후속 작업
   - 번호 목록, 예) 1. 담당자에게 마감 알림 메일 초안 작성
   - 각 작업에 사용할 GWS 기능 표시

5. 선택지
   - 번호로 승인 / 전체 승인 / 취소
