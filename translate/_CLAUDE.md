# CLAUDE.md (한글 번역본)

`agent1114` 프로젝트 전체 규칙입니다. Claude Code는 세션을 시작할 때마다 이 문서를 읽고, 모든 작업의 기준으로 삼습니다.

## 1. 프로젝트 목적

- Notion DB를 조회·분석하고, 트리거 키워드로 항목을 등록합니다.
- 승인된 작업은 GWS CLI로 이어서 실행합니다(메일, 파일, 일정).

## 2. 작업 진행 규칙 (선 보고, 후 실행)

- 사용자가 요청한 모든 작업은 먼저 진행할 단계를 담은 **todo list**로 보고합니다.
- 사용자가 todo list를 승인하기 전에는 작업을 실행하지 않습니다.
- 사용자가 수정을 요청하면 todo list를 고친 뒤 다시 승인을 받습니다.

## 3. 요청 분기 규칙

- `키워드: 내용` 형식의 요청 → **notion-db-register** 스킬로 등록 흐름을 진행합니다.
- 키워드가 없는 일반 요청(예: "오늘 마감 작업 확인해줘") → **notion-db-analyze** 스킬로 분석 흐름을 진행합니다.

## 4. 절대 규칙

- Notion 쓰기, 메일 발송, 파일 생성은 반드시 **사용자 승인 후에만** 실행합니다.
- 승인 전에는 항상 미리보기(`templates/register-preview.md` 또는 `templates/report.md`)를 보여줍니다.
- 모든 실행 결과는 `logs/actions.md`에 기록합니다.

## 5. 역할 분담 (서브에이전트)

| 서브에이전트 | 담당 |
|---|---|
| `notion-analyst` | 조회·분석(읽기 전용), 날짜·상태·담당자 등의 조건으로 필터링 후 결과 보고 |
| `notion-writer` | DB 표 제작, 일정을 트리거 기준으로 분류·등록, 승인된 항목 수정 |
| `gws-executor` | 승인된 GWS 후속 작업 모두 실행, 메일은 초안 작성 후 발송 승인 시 전송 |

## 7. 문서 작성 및 번역 규칙

- 이 프로젝트의 모든 `.md` 파일은 **영어**로 작성합니다.
- 각 `.md` 파일의 한글 번역본은 프로젝트 루트의 `translate/` 폴더에 따로 저장합니다.
- `translate/` 안의 모든 파일·폴더 이름 앞에는 `_`를 붙입니다.
  - 예: `CLAUDE.md`의 번역본 → `translate/_CLAUDE.md`
  - 예: `.claude/` 폴더의 번역본 → `translate/_claude/`
- `translate/` 아래에는 원본과 같은 디렉터리 구조를 유지합니다(예: `docs/workflow.md` → `translate/_docs/_workflow.md`).
- 영어 `.md` 파일을 만들거나 수정하면, 같은 작업 안에서 한글 번역본도 만들거나 갱신합니다.

## 8. 응답 언어 및 형식

- 사용자에게는 **한국어**로 답변합니다(문서 파일은 7번 규칙에 따라 영어로 유지합니다).
- 날짜는 `YYYY-MM-DD(요일)` 형식으로 표기합니다.
