# gws-execute

승인된 후속 작업을 GWS CLI(`gws`) 명령으로 실행합니다.

## 사전 준비

- `gws` CLI가 설치되어 있고 사용자의 Google 계정으로 인증되어 있어야 합니다.
- `gws`를 사용할 수 없으면 중단하고, 설치와 인증이 필요하다고 사용자에게 알립니다.

## 참조 문서

위치: `.claude/skills/gws-execute/references/`

| 작업 종류 | 참조 문서 |
|---|---|
| 메일 | `references/gmail.md` — 초안 생성, 발송, 템플릿 변수 채우기 |
| 파일 | `references/drive-docs.md` — 문서·시트 생성, 폴더 지정 |
| 일정 | `references/calendar.md` — 일정 등록, 시간대(Asia/Seoul), 알림 설정 |

위 파일이 없으면 `gws-skill` 스킬(`.claude/skills/gws-skill/references/`)의 명령 문법을 사용합니다. 명령은 `.claude/skills/gws-skill/scripts/gws.sh`로 실행해야 `.env`의 인증 정보가 적용됩니다.

## 처리 절차

1. **작업 종류 확인**
   - 각 후속 작업을 메일, 파일, 일정 중 하나로 분류합니다.

2. **참조 문서를 읽고 명령 구성**
   - `references/`에 해당 참조 문서가 있으면 읽고, 그에 따라 명령을 구성합니다.
   - 없으면 `gws --help`(와 하위 명령 help)로 문법을 확인하고, 참조 문서가 없었다고 사용자에게 알립니다.
   - 메일은 `templates/email/`에 맞는 템플릿이 있으면 템플릿 변수를 채우고, 없으면 본문을 직접 작성합니다.

3. **명령 미리보기를 보여주고 승인 요청**
   - 실제로 실행할 `gws` 명령과 각 명령이 하는 일(받는 사람, 제목, 파일 이름, 일정 시간 등)을 요약해 보여줍니다.
   - 사용자의 응답을 기다립니다.
     - **승인** → 4단계로 진행합니다.
     - **수정 요청** → 고친 뒤 미리보기를 다시 보여줍니다.
     - **거절 / 응답 없음** → 중단합니다. 실행하지 않습니다.

4. **`gws-executor` 서브에이전트로 실행**
   - 승인된 명령과 사용자가 승인했다는 사실을 넘깁니다.
   - **메일은 2단계로 처리합니다.**
     1. 초안만 만들고, 사용자에게 초안 내용과 링크를 보여줍니다.
     2. 사용자가 발송을 따로 승인한 뒤에만 발송합니다. 승인하지 않으면 초안 상태로 둡니다.

5. **결과 링크 보고**
   - 메일 초안 링크(와 발송 여부), 파일 링크, 일정 링크를 보고합니다.
   - 실패하거나 일부만 성공하면 성공한 작업과 실패한 작업을 원인과 함께 나눠 보고합니다.

6. **기록**
   - 실행한 명령과 결과를 `logs/actions.md`에 기록합니다.

## 규칙

- 승인되지 않은 명령은 실행하지 않습니다.
- 메일 초안 작성 승인은 발송 승인이 아닙니다.
- 이 스킬에서 `gws` 명령을 직접 실행하지 않습니다. 항상 `gws-executor` 서브에이전트를 사용합니다.
